Python Practicals: File Handling, Modules, Packages and Directories

This ZIP contains simple Python solutions based on the uploaded file-handling.docx:
- 23 File Handling programs (root folder)
- 14 Modules / Packages / Directory exercises (modules_packages_directories folder)

How to run:
1. Extract the ZIP.
2. Open the folder in VS Code or a terminal.
3. Run a standalone program with: python3 filename.py
4. For a module/package exercise, open its numbered folder and run: python3 main.py

Some file-handling exercises use student.txt, which is created by program 01. Run it first
if you want to use programs that read student.txt. Programs 17–20 create their own sample CSV data.
The comment-removal exercise expects an existing Python source file.
